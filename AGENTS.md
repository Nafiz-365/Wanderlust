# Wanderlust

Next.js 16.4 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui (base-nova style). All app code lives in `src`; routes live in `src/app`. Early stage: only the `/` route exists so far.

## Commands

- npm is the package manager (`package-lock.json` is the only lockfile).
- `npm run dev` — dev server at http://localhost:3000 (Turbopack is the default bundler in Next 16).
- `npm run build` — `next build`; runs the TypeScript check as part of the build; required before `npm run start`.
- `npm run start` — production server (run `build` first).
- `npm run lint` — ESLint v9 flat config (`eslint.config.mjs`).
- Fast type check without a full build: `npx tsc --noEmit` (there is no `typecheck` script).
- No test script or test runner is installed — `npm test` does not exist; do not look for one.
- Verification order: `npm run lint` → `npm run build` (the build covers typecheck; there is nothing after it).

## Stack & conventions

- App Router: pages/layouts under `src/app`; root layout is `src/app/layout.tsx` (exports `metadata`, loads Geist/Josefin Sans via `next/font/google`, uses Next's generated `LayoutProps<"/">` type).
- Path alias `@/*` → `./src/*` (configured in `tsconfig.json`).
- Tailwind CSS v4, CSS-first: all imports/tokens in `src/app/globals.css` (`@import "tailwindcss"`, `tw-animate-css`, `shadcn/tailwind.css`); there is no `tailwind.config.js` (`components.json` sets `tailwind.config: ""`). Use `@custom-variant dark` for dark mode. CSS goes through the `@tailwindcss/turbopack` loader rule in `next.config.ts`.
- shadcn/ui: style `base-nova`, primitives in `src/components/ui` (`@/components/ui`) built on **Base UI** (`@base-ui/react`) — not Radix; do not add `@radix-ui/*` imports. `cn()` helper at `src/lib/utils.ts` (`@/lib/utils`, re-exports the `cn` package, not clsx/tailwind-merge). Icons from lucide-react. Add components with `npx shadcn add <name>`.
- React Compiler is enabled (`reactCompiler: true` in `next.config.ts`, `babel-plugin-react-compiler` devDependency): components are auto-memoized — do not add `React.memo`/`useMemo`/`useCallback` for performance. `"use client"` / `"use server"` directives still apply where needed.
- Nav links in `src/components/Navbar.tsx` target routes that don't exist yet (`/destinations`, `/bookings`, `/admin`, `/profile`, `/login`, `/signup`) — build those pages rather than searching for them. Site images live in `public/images/`.

## Gotchas

- `.next/`, `out/`, `build/`, `next-env.d.ts`, and `.env*` are gitignored — never commit them.
- ESLint ignores `.next`, `out`, `build`, and `next-env.d.ts` (overrides in `eslint.config.mjs`).
- `AGENTS.md` between the BEGIN/END markers is regenerated by `next dev` — keep that block intact; commit it with your changes.
